> repo

Manage multiple Git repositories from a single workspace. Discover, inspect, and batch-operate across repos with an interactive terminal UI.

Download Latest Release View on GitHub

// features

🔍

Auto-Discovery

Automatically finds all Git repositories in your workspace directory. No config files needed.

⌨

Interactive TUI

Multi-select repos with space bar, confirm with enter. Safe, visual batch operations.

⚡

Parallel Scanning

Scans 50+ repos in under 2 seconds using Rayon parallel processing.

🛠

Batch Operations

Checkout, pull, push, commit, and status across multiple repos in one command.

🛡

Error Resilience

One repo failure doesn't stop the batch. Per-repo error reporting keeps you informed.

🌐

Cross-Platform

Works on Windows, macOS, and Linux. Native binaries with ANSI color output.

// install

$ cargo install --path . $ repo --help
# Windows $ ./target/release/setup.exe # macOS / Linux $ ./target/release/setup # Then restart terminal $ repo --help
# Windows PowerShell $ Copy-Item target\release\repo.exe $env:USERPROFILE\.cargo\bin\ # macOS / Linux $ cp target/release/repo ~/.cargo/bin/

// commands

CommandDescription
repo listList all repos with branch, last commit, dirty state
repo checkout <branch>Switch branch in selected repos
repo pullPull latest changes in selected repos
repo pushPush commits in selected repos
repo commit -m <msg>Stage all + commit in selected repos
repo statusShow git status in selected repos
