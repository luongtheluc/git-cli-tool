> repo

Manage multiple Git repositories from a single workspace. Discover, inspect, and batch-operate across repos with an interactive terminal UI.

Download Latest Release View on GitHub

// features

🔍

Auto-Discovery

Automatically finds all Git repositories in your workspace directory. No config files needed.

⌨

Interactive TUI

Multi-select repos with space bar, confirm with enter. Safe, visual batch operations.

⚡

Parallel Scanning

Scans 50+ repos in under 2 seconds using Rayon parallel processing.

🛠

Batch Operations

Checkout, pull, push, commit, and status across multiple repos in one command.

🛡

Error Resilience

One repo failure doesn't stop the batch. Per-repo error reporting keeps you informed.

🌐

Cross-Platform

Works on Windows, macOS, and Linux. Native binaries with ANSI color output.

📊

Audit Health Check

Offline audit across all repos: uncommitted, unpushed, behind remote. Color-coded table with CI-friendly exit code.

// tutorial

1

Set up your workspace

Create a folder and clone your repos into it as direct children:

$ mkdir ~/workspace && cd ~/workspace $ git clone git@github.com:org/api-service.git $ git clone git@github.com:org/auth-service.git $ git clone git@github.com:org/frontend.git
2

List and inspect repos

See all repos at a glance — branch, last commit, and dirty state:

$ repo list REPO BRANCH LAST COMMIT ────────────────────────────────────────────────────────────── api-service develop a12bc3 fix auth bug auth-service main 7a91de update deps * frontend feature/ui 0ab221 add layout
3

Batch checkout + pull

Switch all repos to develop and pull latest code. Select repos with Space, confirm with Enter:

$ repo checkout develop $ repo pull
4

Commit and push across repos

Stage all changes and commit with a shared message, then push:

$ repo commit -m "fix: update API response format" $ repo push
5

Run any git command

Pass arbitrary git commands to all selected repos with repo git:

$ repo git -- log --oneline -5 $ repo git -- stash $ repo git -- diff --stat
6

Build and test in parallel

Auto-detects build tool (npm, cargo, go, make) per repo:

$ repo run build --jobs 4 $ repo run test --jobs 0 # auto: CPU/2 concurrent
7

Launch the interactive TUI

Full-screen dashboard with status viewer and batch operations — lazygit style:

$ repo ui ┌─ REPOS ──────────────┐┌─ api-service [main] ─────────────────────┐ │▶ ● api-service main ││ M modified src/main.rs │ │ ● frontend dev ││ ?? untracked config/local.toml │ │ worker main ││ A added tests/test.rs │ └──────────────────────┘└──────────────────────────────────────────┘
8

Audit git health across repos

Check all repos offline for uncommitted changes, unpushed commits, and behind-remote status. Works great in CI pipelines:

$ repo audit Repo Branch Uncommitted Unpushed Behind Status ────────────────────────────────────────────────────────────────── api-service main ✗ 3 files ↑ 2 — ⚠ warning frontend feature ✗ 1 file — — ⚠ warning shared-lib main ✓ ✓ ↓ 1 ↓ behind infra main ✓ ✓ — ✓ clean ────────────────────────────────────────────────────────────────── 4 repos | 2 warning(s) | 1 behind | 1 clean # In TUI: press A to run audit, sidebar shows ✓/⚠/✗/↓ per repo $ repo ui # then press A
